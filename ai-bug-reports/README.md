# AI bug reports

Bugs that Claude Code, an AI tool, found in other projects while building Kiln Linux. One report per bug, with the project first in the file name. Each starts with the machine, then the bug, and says what was not checked.

A report goes in only after the bug is repeated with a clean test and looked for in the project's tracker. These were all found on one machine.

This folder is only a record, for developers who come here to read it. Nothing here has been sent to any project. Claude files nothing with a project. Some projects have rules on AI-made contributions, Gentoo's Council among them, so sending a report is the owner's decision, in their own words, under that project's rules.
