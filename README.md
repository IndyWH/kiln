# Kiln Linux

Kiln Linux is a Gentoo-based distribution with Claude as a built-in sidekick.

Claude studies the hardware, builds every program for that exact CPU, tunes the system for desktop use, and looks after it when you chat with Claude Code in the terminal. The desktop is Hyprland on Wayland. Underneath, it is always an ordinary Gentoo system.

Kiln Linux is based on Gentoo. It is not made or endorsed by the Gentoo Foundation or by Anthropic.

## Status

Stage 1, a personal prototype on one machine, is being planned. Nothing is ready to install yet.
